# Introduction
- A cross-compiler is a compielr that runs on platform A (the host) but generate executables for platform B (the target).
- The operating system you are developing is ALWAYS going to be different from operating system you currently use.

## Why cross-compilers are necessary
- Compiler -> CPU, OS
