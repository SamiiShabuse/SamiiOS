# Security Policy

## Scope

SamiiOS is a local learning project for operating-system development. It does not currently ship production software or network services.

## Reporting a Concern

If you find a security-relevant issue, unsafe instruction, or accidentally committed credential, report it privately to the repository owner.

## Do Not Commit

- Personal credentials or tokens
- Local machine paths that expose private information
- Large generated binaries unless they are intentional release artifacts
- Toolchain downloads or third-party source archives that should be fetched separately
