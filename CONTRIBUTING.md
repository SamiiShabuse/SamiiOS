# Contributing

SamiiOS is an early-stage operating-systems learning repository. Contributions should make the learning path clearer, more reproducible, or more technically accurate.

## Good Contributions

- Correct or clarify OS development notes.
- Add reproducible setup commands.
- Document QEMU or cross-compiler troubleshooting.
- Add small implementation milestones with build and boot instructions.
- Improve repository organization without overstating project status.

## Contribution Guidelines

- Keep claims honest: mark planned features as planned, not complete.
- Include exact commands for build or boot steps when implementation code is added.
- Prefer small, reviewable changes.
- Cite or link references when notes are based on external OSDev material.

## Validation

For documentation changes, check links and formatting. For future code changes, include the command used to build and boot the image in QEMU.
